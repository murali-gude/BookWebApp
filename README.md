BookWebApp

A simple web application for managing book records using Java, Servlets, JDBC, JSP, and MySQL.

Features

Add new books

Edit book information

Delete books

View all books

Database-backed using MySQL

Follows MVC structure

Technologies Used

Java

Servlets

JSP

JDBC

MySQL

HTML & CSS

Project Structure

Servlets for handling requests

JDBC for database operations

JSP pages for the user interface

MySQL for storing book details

How It Works

User submits a form (Add / Edit book)

Servlet processes the request

JDBC interacts with the database

JSP displays the result or updated list
